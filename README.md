# 🌐 BeamMP - Play BeamNG drive with your friends

[![](https://img.shields.io/badge/Download-BeamMP-blue.svg)](https://github.com/icecold-dressing124/BeamMP)

## 📌 What is BeamMP

BeamMP adds multiplayer to the simulation game BeamNG.drive. This mod lets you drive with other people on the same map in real time. You see their cars, and they see yours. The software connects your game to various servers hosted by the community. You can join racing servers, roleplay servers, or public open driving sessions.

## 💻 System Requirements

Your computer needs to meet these basic standards to run the mod:

*   **Operating System:** Windows 10 or Windows 11
*   **Game:** A legitimate copy of BeamNG.drive installed via Steam
*   **Storage:** At least 2 gigabytes of free space for mod files
*   **Internet:** A stable broadband connection for smooth driving

## 📥 How to install the launcher

Follow these steps to get the game running on your Windows computer:

1.  Visit the [official download page](https://github.com/icecold-dressing124/BeamMP) to get the installer.
2.  Find the download button on the page.
3.  Save the file to your desktop or your downloads folder.
4.  Double-click the installer file to start the process.
5.  Follow the prompts on your screen.
6.  Select the folder where you installed BeamNG.drive if the installer asks for your game path.
7.  Wait for the progress bar to finish.

## 🚀 Setting up the game

Once the installer finishes, look for the BeamMP icon on your desktop. This icon opens the launcher.

1.  Open the BeamMP launcher with a double click.
2.  The launcher checks for updates every time you open it. Let it finish any downloads.
3.  Click the Play button in the launcher.
4.  The game starts automatically.
5.  Wait for the main menu to appear.
6.  Click the Multiplayer button that now sits on your main screen.
7.  A list of available servers appears.

## 🗺️ Choosing a server

The server list shows many options for players. Each server has a name, a current map, and the number of active players.

*   Look for a low ping value. Ping shows the connection speed between you and the server. Lower numbers mean less lag.
*   Pick a server with an open slot.
*   Click the Connect button next to the server name.
*   The game automatically downloads the map and vehicle assets required for that server. This happens only once per new map.

## 🛡️ Troubleshooting common issues

Most problems have simple fixes. Check these points if the game fails to load:

**The launcher does not start**
Ensure you have the latest version of Windows installed. Check your antivirus software. Sometimes antivirus programs block new installers. Allow the BeamMP launcher through your firewall settings.

**The game crashes during startup**
Verify your game files in Steam. Right-click BeamNG.drive in your Steam library, choose Properties, go to Installed Files, and click Verify integrity of game files. This repairs missing or broken game files.

**I cannot find my game path**
The installer tries to find the game automatically. If it fails, navigate to the folder where Steam installed the game. This is usually in `C:\Program Files (x86)\Steam\steamapps\common\BeamNG.drive`.

**Other players look like they jump around**
This happens when your connection fluctuates. Close other programs that use the internet, such as video streaming services or large file downloads, to free up bandwidth for the game.
